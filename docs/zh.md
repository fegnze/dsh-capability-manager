# dsh-capability-manager

[English](<../README.md>) | 简体中文

一个页面管理 **技能（Skill）• MCP • 助理**，并在会话输入框工具栏选择助理。官方 DSH 服务继续负责包安装、原生预设、技能、MCP 与 Agent 执行；本基座只拥有助理能力声明和显式会话绑定，不另造包管理器或 Agent 宿主。

社区 DSH 桌面插件，兼容 DSH 0.2.1-rc.2。

## 状态

助理支持由原生 OpenSpec 变更 `add-assistant-packages` 跟踪。本地单测/路由、原生运行时、安装生效与真实桌面验收分别核对；包存在不代表绑定成功，公开发布与 registry 可用性单独核验。

## 为什么只有一个插件

文件系统技能仍是原生 provider 发现的目录，MCP 服务仍是官方 `@deepseek-ai/dsh-mcp-client` 的配置行；助理则是内聚实现与资源的独立 DSH bundle。本仓库只提供共享管理器和助理基座，不把每个领域的业务实现塞进同一个包。

## 入口

打开左侧边栏 **技能 • MCP • 助理**，它挨着「插件」，是含三个页签的独立页面。当前会话在输入框工具栏选择助理；选择不会启动模型任务。安装/卸载跳转官方「插件」页面，由桌面宿主负责安装、构建脚本批准与重启反馈。仅使用 **desktop** profile，不另起 Web profile，不手改 profile 文件。

## 技能

发现由 `@deepseek-ai/dsh-skill-filesystem` 负责，会话通过原生 `skills` 服务读取。面板按项目、全局和内置来源分组展示原生目录，并按需读取说明正文。

默认本地管理路径只有 `~/.agents/skills` 和 `<项目>/.agents/skills`。经校验的本地技能提供「打开文件夹」与「删除」；内置、虚拟、链接或未授权来源保持只读。删除当前生效技能后出现同名低优先级技能时，按独立条目处理，不联动删除。暂不提供安装流程。

删除后文件放在发现目录之外的同级回收区域兜底，而非提供技能恢复服务。回收区可查看现存文件和可选文本预览，提供「打开文件夹」和逐项移至 macOS 系统废纸篓；不展示原位置、不提供恢复到原位置，不保证删除后的文件仍是有效技能。安全备份保留在发现范围之外。删除前用简短确认列出受影响文件。

## MCP

MCP 服务是配置，不是文件。本插件管理自己配置表单里的服务，把每个已启用的服务作为原生 `mcp-client` 子插件挂载，并通过官方配置编辑器持久化。

- 其他插件或 profile 管理的服务以**只读**列出并标明原因，页面不会声称自己没有的权限。
- 新服务从标准 MCP JSON 一次确认导入并启动。与启停相同的执行检查仍然生效：stdio 条目若环境变量会注入解释器或加载器变量，会在启动前被拒绝。
- 状态表示“已配置/已启用”，不表示“已连通”：进程可能启动失败，任何工具结果都不构成远端服务健康证明。

## 助理

包与基座接口见[运行时契约](<../src/assistants/contract.md>)。助理通过官方插件管理器安装，以严格 manifest、只读就绪检查和作用域挂载回调注册。内容摘要覆盖运行代码与资源，用于漂移检测，不是恶意已安装插件的沙箱或供应链签名证明。

会话最初不绑定助理。输入框预览精确包身份和前置条件后，由已认证主人确认；首版**一个会话终身绑定一个助理**，不做默认、替换或解绑。已有会话在空闲且原生预设匹配时可绑定；自动选择原生预设仅限首 turn 前。已开始且预设不符时保留阻断选择并提供可复制的新会话提示。同一精确身份可重试修复配置，升级需要新会话。

绑定使用官方 `storageDomain` 和标准会话 inbox 证据投影；恢复先核对精确身份和预设。证据缺失、状态损坏、内容漂移或包移除会阻止任务，不静默退回无助理模式。正常包/基座清理不删除用户工程、凭据、共享 MCP 或绑定意图。

输入框只追加控件，不接管宿主发送按钮：显示阻断/准备状态，但没有官方提交准入接口时不能禁用宿主发送。Host 步骤准入是最后防线；拒绝步骤会消费已取出的输入，**不是暂停队列**，基座不会自动重发。基座彻底卸载/停用后不存在拦截点，无法保护未来冷恢复，需恢复基座或新建会话；绑定存储与会话证据同时被销毁不属于可检测范围。

助理工具自行执行基线与授权检查，不声称封死任意 shell/MCP 旁路。子任务模板使用原生 provider 能力及生命周期，按任务显式选择预设/模型/上下文，不自动为子 Agent 绑定父助理。不新增守护、Agent 宿主或流程数据库。

## 授权

HTTP 请求需要签名 Peer 认证、owner 主体与插件意图头；响应不缓存。变更额外要求宿主已认证的 browserPeer（浏览器界面与 Electron 桌面转发共用），owner API 会话不能写入。Host/Origin 边界及签名会话 Cookie 由宿主认证；桌面转发不带 Origin 和 Fetch Metadata，本插件不要求这些头必须存在。Agent 工具只能检查与预览，不能批准或提交变更。

## 配置

`roots` 授权本地技能目录；每项需要 `id`、绝对 `path`、`trusted: true` 与 `recoveryOutsideDiscovery: true`（主人确认同级状态目录位于**所有**实际发现根之外，包括本插件无法枚举的预设与自定义 provider）。额外 `roots` 可选；配置为空时仍可管理上述两个已存在的 `.agents/skills` 默认目录中的删除操作，不会创建缺失的默认目录。项目上下文必须来自活跃会话或已登记工作区，不接受浏览器任意路径授权。`servers` 是本插件自己的 MCP 列表。

没有配置已启用服务时，安装本 bundle 不启动任何 MCP 服务。默认目录不授予任意文件系统访问或安装、编辑权限。

## 限制

- 本地技能管理是受限 **macOS** 适配层，仅面向可信主人本地根与协作式修改；它不是抵御同用户恶意竞争的安全边界，也不是官方跨平台技能安装 API。
- 文件写入成功不代表技能已生效：发现、更近根的同名覆盖、预设作用域与调用策略都由原生机制决定。请核对所选会话，并记住“出现在目录里”不等于“可被调用”。
- MCP 启停通过 Loader 持久化并协调，可能中断进行中的工具调用；进程启动成功也不等于服务健康。
- 不提供市场、不保存凭证、不写 provider 配置、不执行导入的脚本。
- 发现只有一层深度：`<root>/<name>/SKILL.md` 与 `<root>/<name>.md`。

## 开发

运行 `node --test test/*.test.mjs`。控制器/HTTP/React DOM 与原生运行时、真实桌面验收分开报告。本次助理体系迁移使用原生 OpenSpec，主人明确豁免旧 devkit 约束；替代工具通过能力对等与桌面验收后才迁移领域权威入口。公开发布仍需授权与独立包核验。
